# Hazelune

Tek dosyalık anasayfa ve dijital menü: **`index.html`**

## Siteyi açmak

GitHub kodu gösterir, siteyi açmaz. Şunu yapın:

1. Bu klasördeki `index.html` dosyasını bilgisayara indirin
2. Dosyaya çift tıklayın — tarayıcıda açılır

Menü, yazı tipi yedekleri ve kruvasan görseli bu tek dosyanın içindedir. İnternet olmasa da açılır.
