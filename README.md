# Hazelune

## Siteyi açmak

Sadece `index.html` indirme. Tüm klasörü indir:

1. GitHub’da yeşil **Code** → **Download ZIP**
2. ZIP’i aç
3. İçindeki `index.html` dosyasına çift tıkla

Klasör şöyle olmalı:

```
Hazelune/
  index.html
  images/
    hero-croissant.jpg
    serpme-kahvalti.jpg
    latte.jpg
    ...
```

## Görseller

Ölçü şart değil. Dosya adı menüdekiyle aynı olsun: `serpme-kahvalti.jpg`

GitHub’daki `images` klasörüne yüklenen fotoğraflar `index.html` içine de işlenir. Yeni `index.html` indirince menüde görünür.
